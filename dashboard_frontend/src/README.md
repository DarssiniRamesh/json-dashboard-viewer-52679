# Oceanic Analytics Dashboard (Frontend - `/src`)

This React-based dashboard provides interactive analytics and visualizations from data in appvote.json.

**Features:**
- Modern, oceanic blue/white UI — responsive and beautiful
- Bar/line charts for trends (votes, submissions)
- Word cloud for third-party integrations
- Sentence cloud for challenge phrases
- Top 10 apps (overall and per week), with images/links
- Key stats summary, unique features block
- Zero PII/user analytics — only aggregated, public data
- Easily update data: replace `appvote.json`, hot reloads!

**Live Coding Requirements**
- All code and UI is in `/src`
- Needs `chart.js`, `react-chartjs-2`, `react-wordcloud` installed
- Data is loaded dynamically from static appvote.json in `/src`
- Fully responsive for mobile and desktop
